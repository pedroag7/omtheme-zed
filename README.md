# Om Theme for [Zed](https://zed.dev)

A darker Dracula theme for Zed, with and without italics.

## Variants

- **Om Theme** (default Dracula italics)
- **Om Theme (Night Owl Italic)**
- **Om Theme (No Italic)**
- **Om Theme (Blurred)**
- **Om Theme (Night Owl Italic, Blurred)**
- **Om Theme (No Italic, Blurred)**

## Install locally

1. Copy `themes/omtheme.json` to your Zed themes directory:
   - **Windows:** `%APPDATA%\Zed\themes\`
   - **macOS/Linux:** `~/.config/zed/themes/`
2. Open Zed's theme selector and choose one of the **Om Theme** variants.

## Install as a dev extension

1. Open the Extensions page in Zed.
2. Click **Install Dev Extension** and select this folder.
